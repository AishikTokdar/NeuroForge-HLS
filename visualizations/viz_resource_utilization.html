The Key Tradeoff: We traded BRAM (23% → 65%) for LUT reduction (83% → 58%) and significant speedup (12.0×). On-chip buffering mitigated memory access latencies at the cost of using block RAM. This is the classic FPGA optimization pattern: leverage on-chip memory to stream data to parallel MAC units efficiently.

💡 Key Lessons

  • Memory bandwidth vs compute balance: The 2.0× system memory overhead (12.4ms fabric vs 24.8ms system) is managed effectively using double-buffered AXI4 tile streaming.
  • On-chip buffering is critical: Using 65% of BRAM enabled the 12.0× speedup from baseline. Every tile buffered in BRAM saves hundreds of DDR access cycles.
  • Clock relaxation helped: Increasing clock period from 10ns to 15ns gave tools breathing room for optimization and achieved timing closure with positive slack.
  • Parallel compute mapping: Allocating 64 DSP slices for parallel MAC operations achieved high throughput while remaining well within device limits.
