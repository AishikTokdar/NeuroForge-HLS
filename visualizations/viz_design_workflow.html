Fixed-Point Conversion
Python script (convert_weights.py)
Convert INT32 quantized weights to ap_fixed<16,12> format (Q12.4) compatible with HLS. This involves rescaling from scale factor 65536 (2^16) to 16 (2^4).
# INT32 uses scale of 65536 (2^16) # ap_fixed<16,12> needs scale of 16 (2^4 fractional bits) fp32_data = int32_data / 65536.0 fixed_data = np.round(fp32_data * 16.0) fixed_data = np.clip(fixed_data, -32768, 32767) return fixed_data.astype(np.int16)

🎓 Key Takeaways

  • HLS abstracts hardware: C++ instead of VHDL makes FPGA accelerator modeling accessible in software.
  • Simulation is fast & accurate: HLS C-simulation runs in seconds, matching PyTorch output with zero error (MSE=0).
  • Fixed-point is tricky: Choosing the right Q format (ap_fixed<16,12>) requires verification to avoid overflow.
  • Theoretical modeling: Software HLS synthesis provides accurate latency and resource estimates without physical hardware deployment.
