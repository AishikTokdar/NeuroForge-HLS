    The original exported kernels were all zero. They could not be recovered by rescaling. A replacement was trained using the same architecture, with both checkpoints and binary exports saved.

    1. 45,000 training imagesRandom crops and horizontal flips; seed 42.

    07

    What the evidence establishes.

    A working software pipeline is a useful milestone. Hardware readiness is a separate claim, with separate checks.

    Verification scope
    C++ functional inference
    All 10,000 class predictions matched the PyTorch reference. Maximum absolute logit difference: 0.0000190735.
    Verified
    Trained weight exports
    FP32, genuine Q16.16 integers and Q12.4 parameters were reloaded and checked. Both model checkpoints and hashes are retained.
    Verified
    Standalone golden vector
    A real CIFAR-10 cat image, ten nonzero logits, MSE 2.09894e−12 and 0/10 output errors.
    Verified
    Fixed-point numerical behavior
    Quantization-aware evaluation and cast-range audits are approximate software models. Vendor math and default wrap behavior still need direct simulation.
    Approximate
    RTL, timing and resources
    Vitis synthesis, C/RTL co-simulation, routed timing and physical resource reports have not been run. The Zynq-7020 is a target, not a tested deployment.
    Pending
    Board and system integration
    No physical board run, measured power, DDR trace or complete board host driver is claimed.
    Not tested

    08

    The project, beyond the charts.

    NeuroForge-HLS connects a trained image classifier to a hardware-oriented C++ implementation. It is a reproducible software study of that boundary.

    Project information

    A ReducedVGG accelerator study.

    The network accepts normalized 32×32 RGB images from CIFAR-10 and produces ten class scores. Convolution uses spatial tiles and small output-channel groups, with BatchNorm, ReLU, pooling and fully connected layers implemented in C++.

    The original all-zero weight exports were replaced with a newly trained model. Export formats, quantization checks, golden-vector generation and repeatable validation are included in the repository.

    Target device
    XC7Z020CLG400-1
    Clock constraint
    15 ns · not closed timing
    Feature / weight type
    ap_fixed<16,12>
    Accumulator
    ap_fixed<32,24>

    BatchNorm intermediates use ap_fixed<48,24> to keep epsilon representable. The NO_HLS build uses floating-point arithmetic. No browser-side model inference is performed on this site.
